# ONE PATRON

ONE PATRON is a conceptual artwork by Alexander List: one patron, at least USD 1,000,000 in cryptocurrency, and nothing sold in return.

This repository preserves the public-facing texts, visual identity, published fictional cycle, website source and selected production assets of the project.

## Start here

- Project: https://one-patron.netlify.app/
- Terms & Conditions: https://one-patron.netlify.app/terms/
- Verify identity & wallets: https://one-patron.netlify.app/verification/
- Stories: https://alexanderlistart.substack.com/

## Repository structure

- `brand/` — current public visual identity masters and standards.
- `stories/` — published story texts and approved covers.
- `site/` — source of the current public website.
- `social/` — current public social-media assets.
- `media/` — selected public audiovisual works.
- `source-code/` — scripts used to produce project assets.
- `provenance/` — public record links and rights notice.

The unreleased hidden-score architecture, owner runbooks, private drafts and superseded variants are intentionally not included in this public subset.

See `provenance/RIGHTS_NOTICE.md` for rights information.
