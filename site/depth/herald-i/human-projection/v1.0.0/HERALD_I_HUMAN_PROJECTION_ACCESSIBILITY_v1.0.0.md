## Concise structural description

The fresco presents one oriented cycle made from exactly twenty-one vertices and twenty-one edges. The cycle is divided into three contiguous seven-element families:

- C1: A-local boundary segment, shown with solid edges and square vertex marks;
- C2: relational interface segment, shown with dashed edges and diamond vertex marks;
- C3: B-local boundary segment, shown with dotted edges and circular vertex marks.

The families are structurally different but not ranked.

At the center, text reports the currently inspected G0 outcome. In the initial view G0 is available at S07 and no recipient branch is selected. The viewer may inspect three declared branches:

1. `DECLINE` returns to S07 and does not close the cycle.
2. `DEFER` moves to S08 and does not close the cycle.
3. `ENTER_COMPATIBLE`, when the declared compatibility condition holds, produces `CLOSURE_CONFIGURATION_R_AB` and attaches one order-2 cell along the full existing boundary.

When the compatible branch is selected, a translucent fill appears inside the cycle. The fill has no stroke and does not represent an edge. All twenty-one original edges remain visible and unchanged. No twenty-second edge is created. The displayed homology summary changes from beta-one 1 to beta-one 0.

An optional projection-local replay emphasizes the existing edges using the declared reference mode indices 3 and 6. It does not move vertices, add edges, or change machine state.

## Keyboard behavior

The interactive reading order is:

1. skip link;
2. Decline branch;
3. Defer branch;
4. Enter compatible branch;
5. Reset to available;
6. replay/stop structural modes;
7. provenance and Machine Mode disclosure;
8. exact machine-file links.

All interactive elements are native HTML buttons, links, or a `details/summary` disclosure. They are operable with standard keyboard controls.

Pressed branch and mode states are exposed through `aria-pressed`. Outcome changes are announced through an `aria-live="polite"` region.

## Focus

All keyboard-focusable elements receive a visible gold outline with offset. Hover styling is not used as the only interaction indication.

## Color independence

Color is secondary. Structural families are also distinguished by:

- solid, dashed, and dotted edge patterns;
- square, diamond, and circular vertex shapes;
- exact textual family labels.

Closure is communicated through the membrane, central status text, beta-one statement, order-2 cell count, and outcome announcement. It is not conveyed by color alone.

## Motion and reduced motion

The default projection contains no continuous animation. Motion begins only after activation of `Replay modes 3 + 6`.

Under `prefers-reduced-motion: reduce`, activating the mode control applies a static deterministic mode phase rather than animation. All structural information remains available. The G0 branch views do not require continuous motion.

## Script and graphics fallback

The SVG contains a title and detailed description. A `noscript` summary states:

- 21-edge oriented cycle;
- three seven-edge families;
- conditional G0 event;
- order-2 cell attachment;
- no twenty-second edge.

Exact machine files remain available through Machine Mode links outside the SVG.

## Responsive behavior

Desktop and tablet use a large artwork field with a separate structural key. At narrower widths the key moves below the artwork, and the operator controls wrap or stack.

The SVG keeps a stable viewBox and deterministic geometry at every viewport. Responsive changes scale and rearrange presentation only; they do not change the topology, edge count, family membership, G0 outcomes, or closure semantics.

Validation widths:

- required: 1440, 1024, 768, 390;
- defensive: 1280, 834, 430, 375.

Page-level horizontal overflow is prohibited.
